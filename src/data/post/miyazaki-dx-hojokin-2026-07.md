「宮崎県に、DXに使える補助金があると聞いたのですが」というご相談をいただくことが増えました。

おそらく多くの方が指しているのは、**宮崎県の「産業DX推進事業費補助金」** です。結論から書くと、**令和8年度分は導入タイプ・発展タイプとも受付が終了しています。**

ただ、それで話が終わりではありません。県には**別枠のDX補助金**があり、そちらは**令和8年8月7日（金）まで二次募集を受付中**です。

![宮崎県のDX補助金、今年度分は受付終了。ただし次の入口は開いている](~/assets/images/column-miyazaki-dx-2026-07/hero.png)

この記事では、県公式の情報をもとに次の3点を整理します。

1. 産業DX推進事業費補助金は、そもそもどういう制度だったのか
2. 今まさに公募中の「物価高騰対策DX推進事業費補助金（二次募集）」
3. 次の公募に向けて、今のうちにやっておくべき準備

---

## 1. 産業DX推進事業費補助金（令和8年度）とは

宮崎県が実施している、県内の中小企業・小規模事業者向けのDX補助金です。タイプが2つに分かれています。

| | 導入タイプ | 発展タイプ |
| --- | --- | --- |
| 対象事業 | 市販パッケージなどのデジタル技術等の導入 | システム構築やデータを活用した新規事業の構築など |
| 補助上限額 | 250万円 | 1,000万円 |
| 補助下限額 | 100万円 | 200万円 |
| 補助率 | 1/2 | 1/2 |
| 成果目標 | 作業工数・時間を12.5%以上削減 | 労働生産性を年1%ずつ増加（3年で3%以上） |
| 申請方法 | 電子申請システム「Jグランツ」 | 電子メール |
| 受付期間 | 令和8年4月24日〜6月12日（必着） | 令和8年4月24日〜6月30日（必着） |

**両タイプ共通の要件**として、IPAの「SECURITY ACTION」の**★★（二つ星）宣言**を補助事業完了日までに実施することが求められます。

対象となるのは、県内に本社等を有する中小企業・小規模事業者等で、県税の未納がないことなどが条件です。

### この制度の性格

注目したいのは、導入タイプの成果目標が「**作業工数・時間を12.5%以上削減**」である点です。

つまりこの補助金は、**今ある業務をデジタルで効率化する取組**を正面から対象にしています。既存業務の省力化のためにツールを入れる、という使い方が本筋の制度です。

## 2. 国の「新事業進出・ものづくり商業サービス補助金」とは別物です

よく混同されるのですが、**国の補助金とはまったく別の制度**です。財源も窓口も審査もすべて違います。

当社では先日、国の[新事業進出・ものづくり商業サービス補助金についてのコラム](/news/shinjigyou-monodukuri-2026-07)も書きました。あわせて読んでいただくと違いが分かりやすいと思います。

| | 宮崎県 産業DX推進 | 国 新事業進出・ものづくり商業サービス |
| --- | --- | --- |
| 実施主体 | 宮崎県 | 国（中小企業庁） |
| 対象者 | 宮崎県内の中小企業等 | 全国の中小企業等 |
| 狙い | 既存業務の効率化・省力化、DXの実現 | 革新的な新製品・新サービスの**開発**、新市場進出 |
| 補助上限 | 250万円 / 1,000万円 | 750万円〜2,500万円（特例適用時 最大3,500万円） |

![業務効率化を狙う県の制度と、新規開発を狙う国の制度は方向が逆](~/assets/images/column-miyazaki-dx-2026-07/compare.png)

大事なのはここです。

国の補助金は公募要領に、「**単に機械装置・システム等を導入するにとどまり、新製品・新サービスの開発を伴わないものは補助対象事業に該当しません**」と明記されています。

一方、県の産業DX推進は、その「業務効率化のためのシステム導入」こそが対象です。

**狙いが逆を向いています。**

- 業務効率化・省力化のためのシステム導入 → **県の制度**
- 新しい製品・サービスの開発、新市場への進出 → **国の制度**

「DXしたいから、とりあえず大きい方の補助金で」という考え方だと、そもそも制度の趣旨に合わず落ちます。**やりたいことに合う制度を選ぶ**のが先です。

## 3. 今まさに公募中：物価高騰対策DX推進事業費補助金（二次募集）

産業DX推進の受付は終わりましたが、宮崎県には**もう一つDXに使える補助金**があります。

**物価高騰対策DX推進事業費補助金（令和7年度補正予算）** の二次募集が、現在受付中です。

| 項目 | 内容 |
| --- | --- |
| 締切 | **令和8年8月7日（金）** |
| 補助上限額 | 500万円 |
| 補助下限額 | 100万円 |
| 補助率 | 1/2 |
| 対象事業 | 戦略的DX推進事業（課題解決に向けたシステム構築やデータ活用により、収益性や生産性強化を図る取組） |
| 成果目標 | 労働生産性を年1%ずつ増加（3年で3%以上） |
| 申請方法 | Jグランツ（GビズIDプライムが必要）／宮崎県ファイル転送システム |
| 問い合わせ | 宮崎県産業政策課 産業デジタル担当（0985-26-7682） |

対象は県内に本社または主たる事務所を有する中小企業・小規模事業者等。こちらも**SECURITY ACTION の二つ星宣言**が要件に入っています。

### 正直に書いておくべきこと

締切まで日数が限られています。そして申請には **GビズIDプライム** が必要です。

**GビズIDプライムの取得には時間がかかります。** これから取得手続きを始めて今回の締切に間に合うかは、正直なところ厳しい可能性があります。まずは**IDを持っているかどうかを今すぐ確認**してください。持っていなければ、今回は見送って次に備える判断もありえます。

急いで中身の薄い計画を出しても通りません。**間に合わないと判断したら、次の公募に照準を合わせる**方が結果的に近道です。

## 4. 次の公募に向けて、今のうちにやっておけること

補助金は、公募が始まってから動き出すと間に合いません。産業DX推進事業費補助金は令和7年度・令和8年度とも**4月中旬〜下旬に公募開始**という流れでした（令和7年度は4月18日開始、令和8年度は4月24日開始）。次年度も同じ時期と仮定すると、動き出すべきは**年明け〜3月**です。

公募開始を待たずに、今からできることが4つあります。

![GビズIDプライム、SECURITY ACTION二つ星、作業工数の可視化、着手タイミングの4つの準備](~/assets/images/column-miyazaki-dx-2026-07/prepare.png)

### ① GビズIDプライムを取得しておく

多くの補助金がJグランツ申請です。**取得に時間がかかるので、公募が出てからでは遅い**というのが実感です。持っていない事業者さんは、これだけでも先にやっておく価値があります。

### ② SECURITY ACTION ★★（二つ星）を確認しておく

県のDX補助金は、いずれも二つ星宣言が要件に入っています。二つ星は情報セキュリティ基本方針の策定と公開が必要です。**これも直前に片づけられる性質のものではありません。**

### ③ 「どの業務が、何時間かかっているか」を数える

導入タイプの成果目標は「作業工数12.5%以上削減」でした。ということは、**削減前の数字がないと目標が書けません。**

「なんとなく大変」では申請書になりません。誰が、どの作業に、月何時間使っているのか。**現状の数字を持っている事業者が圧倒的に強い**です。今のうちに数え始めてください。

### ④ 交付決定前に発注しない、を徹底する

補助金全般に共通しますが、**交付決定より前に発注・契約した経費は対象外**になるのが原則です。「先に作り始めておこう」は最も損をするパターンです。着手のタイミングは必ず事前に確認してください。

## 5. 次の公募が出たら、このコラムでお知らせします

宮崎県のDX関連補助金は、**産業DX推進**と**物価高騰対策DX推進**が別々に動いており、後者は年度途中に二次募集が出ています。つまり、**年に一度の一発勝負ではありません。**

当社では県の公募情報を継続的に確認しています。**新しい公募や二次募集が出たら、このコラムであらためてお知らせします。**

「今すぐは動けないけれど、次があるなら準備しておきたい」という方は、上の4つの準備だけ進めておいてください。それだけで、次の公募が出たときのスタートがまったく変わります。

## ぼんどでお手伝いできること

はっきりさせておくと、**当社は補助金の申請代行や認定支援機関としての業務は行っていません。** そこは中小企業診断士や認定支援機関の領域です。

私たちがお手伝いできるのは、システム・DX側です。

- **どの業務をデジタル化すると、実際に時間が減るのかの整理。** 効果の出ない場所に投資しないための切り分けです
- **現状の作業工数の可視化。** 申請書に書く「削減前の数字」の土台になります
- **要件定義と、内訳の分かる見積書の作成**
- **交付決定後の実装。** 業務システム、既存ツールとの連携、データの自動集計まで
- **担当者が自分で回せる状態にする。** 私たちがいないと止まる仕組みは、支援ではなく依存だと思っています

**補助金を使わない前提でのご相談も歓迎です。** 「補助金を待つより、月数千円のツールで今日から始めた方が早い」という結論になることもあります。そう思ったときは、そう言います。

## よくあるご質問

**Q. 産業DX推進事業費補助金は、もう申請できませんか？**
令和8年度分は導入タイプ（6月12日必着）・発展タイプ（6月30日必着）とも受付が終了しています。二次募集の有無については、宮崎県産業政策課（0985-26-7682）にご確認ください。

**Q. 会社のホームページのリニューアルは対象になりますか？**
県のDX補助金は「業務の効率化・省力化」「データ活用による生産性向上」が趣旨です。会社案内サイトの作り直しだけでは趣旨に合いません。ただし予約や受発注など、業務が実際にシステム化される場合は組み立て方によります。

**Q. 市販のクラウドツールを導入するだけでも対象になりますか？**
産業DX推進の導入タイプは「市販パッケージなどのデジタル技術等の導入」が対象です。ただし補助下限額が100万円なので、月数千円のツールを1つ入れるだけでは規模が足りません。

**Q. SECURITY ACTIONの二つ星は難しいですか？**
情報セキュリティ基本方針を策定して自社サイト等で公開する必要があります。手続き自体は難解ではありませんが、方針の中身を考える時間が要ります。早めに着手してください。

**Q. まだ何をしたいか固まっていませんが、相談してもいいですか？**
はい。むしろその段階からの方がよいです。「どの業務が重いのか」の棚卸しからご一緒できます。
